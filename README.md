## 현재 단계

세션1 (2026-08-12) — 포맷 해독 완료. **한글화는 막혀 있다.**

### ★★막힌 지점 — 메인 메뉴 설명문의 폰트 출처 미상
실기로 확정된 것만:
- `.msg` 제자리 편집은 **완전 정상** (꽉 채움 / 짧게+널패딩 / `\n` 개행 전부 반영).
- 대체 SJIS 코드를 써넣으면 **그 코드가 그대로 화면에 나온다** (치환 기법 동작).
- `sprite/Font/` 아틀라스 **28개를 전부 공백으로 만들면 오프닝 자막이 깨진다** → 쓰인다.
- **그런데 같은 빌드에서 메인 메뉴 설명문은 멀쩡하다.** `sprite/`+`menudata/`
  텍스처 202개를 더 비워도 멀쩡 → 그 화면의 폰트는 **다른 곳**에 있다.
- ⇒ 1차 한글화가 빈 상자였던 이유 = 대체 코드가 **그 화면 폰트에 없어서**.
  흔한 가나 12개로만 시험했을 땐 정상 출력됐다.

배제한 것: 사본 없음 / `Font` 디렉터리 하나뿐 / ISO 에 누락·중복 없음 /
XBE 에 시스템폰트·텍스처 없음 / **28×28 격자는 `sprite/Font` 26개뿐**(양성대조 통과) /
`pdtex_gamefont.txb` 는 라틴 전용이고 비워도 영어 라벨이 멀쩡(= 구운 그림).

다음: ①격자 검출기를 칸 크기 16~48 로 확장해 재스캔 ②`.spr` 98개 조사
③xemu 파일 추적 또는 XBE 디스어셈블 ④대체 코드 풀은 **원문에 실제로 쓰인 글자**로.

풀린 것:
- 텍스트 위치·인코딩 (무압축 cp932/ASCII, `.msg` 64개 + `.mnu` 3개)
- 폰트 매핑표 `z_tbl` (SJIS → 글리프 인덱스 **직접 표**, 해시 아님)
- 아틀라스 = PCMP(LZSS) → TXRB → **DXT3 512×512, 28×28 셀 18칸**
- PCMP 코덱 **해제·재압축 양방향** (200/200 해제 성공, 왕복 일치)
- 장면별 글리프 예산 실측

## 도구

```
python tools/msgfile.py      # 텍스트 분량·슬랙 집계
python tools/check_tbl.py    # z_tbl 상한 검산
python tools/cells.py        # ★아틀라스에서 글리프 칸 실측 (예산의 근거)
python tools/atlas_view.py <장면> [폭] [줄수]   # 아틀라스를 PNG 로 (work/atlas/)
python tools/pcmp.py [필터]  # PCMP 전수 해제 검증
python tools/selftest.py     # ★왕복 검증 — 빌드 전 필수
```

모듈: `project.py`(경로·상수) `pcmp.py`(PCMP/LZSS) `dxt.py`(DXT3 디코드·인코드)
`ztbl.py`(매핑표) `msgfile.py`(텍스트 스캔) `atlas.py`(PNG 출력)

## 하드 룰

- ★**빌드는 매번 허락을 받는다.**
- ★**파일 크기는 원본과 같게 유지한다.** Conker Xbox 가 크기를 바꾸면 부팅불가였다.
  Orta 도 같은지 미확인 — 확인 전까지 안전한 쪽으로 간다.
- ★**글리프 수는 아틀라스에서 실측**한다(`cells.py`). z_tbl 의 값 개수나 최대
  인덱스로 세면 센티널 때문에 틀린다.
- ★**Common 아틀라스는 여유가 2칸뿐**이다. 한글은 가나 슬롯 재활용으로 넣는다.
- ★인코더를 손대면 `selftest.py` 를 반드시 통과시킨다.
- 원본 자산은 저장소에 커밋하지 않는다.
